# LiteRT MobileNet-v2 AOT S25 Example

This sample runs Qualcomm MobileNet-v2 with LiteRT `CompiledModel`.

The app has two intended paths:

- Emulator or generic laptop testing: run the Qualcomm float TFLite model from app assets on `Accelerator.CPU`.
- Physical Snapdragon SM8750 device: require Qualcomm NPU, load the AOT-compiled model from a Play AI Pack, and fail visibly if NPU setup is unavailable.

## Important Files

**Start with these files:**

- `tools/prepare_aot_sm8750.py`: downloads Qualcomm MobileNet-v2, prepares CPU assets, fetches LiteRT NPU runtime libraries, runs AOT compilation for SM8750, exports the AI Pack, and copies device targeting config.
- `app/src/main/java/com/example/mobilenetlitert/MobilenetClassifier.kt`: the core runtime logic. This is where CPU and NPU `CompiledModel` instances are created and `model.run(...)` is called.
- `app/src/main/java/com/example/mobilenetlitert/DevicePolicy.kt`: chooses CPU for emulator/generic devices and NPU-required for physical devices.
- `app/build.gradle.kts`: wires the app, CPU assets, AI Pack, SM8750 runtime dynamic feature, and device targeting bundle config.
- `settings.gradle.kts`: conditionally includes the AI Pack and LiteRT runtime modules when `-PenableNpu=true`.
- `gradle.properties`: enables Android Gradle Plugin device targeting support with `android.experimental.enableDeviceTargetingConfigApi=true`.

**Useful supporting files:**

- `app/src/main/java/com/example/mobilenetlitert/ImagePreprocessor.kt`: resizes images to `224x224`, converts RGB pixels to float values in `[0, 1]`.
- `app/src/main/java/com/example/mobilenetlitert/ClassificationPostprocessor.kt`: maps model output scores to top-k ImageNet labels.
- `app/src/main/java/com/example/mobilenetlitert/MainActivity.kt`: Compose UI for sample image, image picker, run button, status, timings, and top-5 predictions.
- `app/device_targeting_configuration.xml`: generated by the AOT/AI Pack export flow and copied into the app module for bundle device-group targeting.
- `ai_pack/mobilenet_v2_sm8750/build.gradle.kts`: generated AI Pack Gradle module.

## CPU Emulator

Open the project in Android Studio or run:

```sh
./gradlew installDebug
```

The debug path downloads the Qualcomm float TFLite asset and runs it with `Accelerator.CPU`. In Logcat, filter on:

```text
MobileNetLiteRT
```

Expected debug behavior:

- backend status shows CPU
- app can classify the bundled sample image or a picked image
- logs show `CompiledModel.run()`
- there is no `Interpreter` API usage

## SM8750 NPU AOT

Qualcomm LiteRT AOT requires Ubuntu 22.04. On macOS or Windows, use Docker Desktop and run the AOT step inside an Ubuntu 22.04 `linux/amd64` container.

**Example image setup:**

```sh
docker build --platform linux/amd64 -t litert-aot-sm8750:ubuntu22 - <<'DOCKERFILE'
FROM ubuntu:22.04
ENV DEBIAN_FRONTEND=noninteractive
RUN apt-get update && apt-get install -y \
    ca-certificates curl wget unzip python3 python3-pip python3-venv \
    lsb-release gnupg software-properties-common build-essential \
    && rm -rf /var/lib/apt/lists/*
RUN wget -q https://apt.llvm.org/llvm.sh -O /tmp/llvm.sh \
    && chmod +x /tmp/llvm.sh \
    && /tmp/llvm.sh 18 all \
    && apt-get update \
    && apt-get install -y libc++-18-dev libc++abi-18-dev \
    && rm -rf /var/lib/apt/lists/* /tmp/llvm.sh
RUN python3 -m pip install --upgrade pip \
    && python3 -m pip install ai-edge-litert-sdk-qualcomm==0.2.0 ai-edge-litert==2.1.2 certifi
DOCKERFILE
```

Run the AOT preparation script from the container:

```sh
docker run --rm --platform linux/amd64 \
  -v "$PWD":/workspace \
  -w /workspace \
  litert-aot-sm8750:ubuntu22 \
  python3 tools/prepare_aot_sm8750.py
```

Then build the NPU AAB:

```sh
./gradlew -PenableNpu=true bundleRelease
```

The generated AAB is:

```text
app/build/outputs/bundle/release/app-release.aab
```

Install the generated AAB locally with bundletool:

```sh
bundletool="java -jar /path/to/bundletool-all.jar"
tmp_dir=$(mktemp -d)
$bundletool build-apks \
  --bundle=app/build/outputs/bundle/release/app-release.aab \
  --output="$tmp_dir/mobilenet.apks" \
  --local-testing \
  --overwrite
$bundletool install-apks --apks="$tmp_dir/mobilenet.apks" --device-groups=Qualcomm_SM8750
```

On physical devices the app requires Qualcomm NPU. If the NPU, AI Pack, or runtime libraries are unavailable, it shows an error instead of falling back to CPU/GPU.

## Flow

This is the full flow used to get the project working.

1. Create a greenfield Kotlin/Compose Android app with a simple classifier UI.

2. Add the LiteRT dependency and use `CompiledModel`.

CPU model initialization:

```kotlin
private fun initializeCpu(): ModelSession {
  val options = CompiledModel.Options(Accelerator.CPU)
  val compiledModel = CompiledModel.create(context.assets, CPU_MODEL_ASSET, options, null)
  Log.i(TAG, "Selected model source=assets/$CPU_MODEL_ASSET accelerators=[CPU]")
  return ModelSession(compiledModel, "CPU")
}
```

Inference:

```kotlin
activeSession.inputBuffers[0].writeFloat(input)
activeSession.model.run(activeSession.inputBuffers, activeSession.outputBuffers)
val logits = activeSession.outputBuffers[0].readFloat()
```

3. Download Qualcomm MobileNet-v2 float TFLite and labels from the Hugging Face release assets JSON.

The Gradle CPU path also downloads the model asset for emulator testing:

```kotlin
val downloadMobileNet by tasks.registering(Download::class) {
  src(
    "https://qaihub-public-assets.s3.us-west-2.amazonaws.com/" +
      "qai-hub-models/models/mobilenet_v2/releases/v0.51.0/" +
      "mobilenet_v2-tflite-float.zip"
  )
  dest(modelZip)
  overwrite(false)
}
```

4. Run LiteRT AOT for Snapdragon SM8750.

Core AOT script:

```python
target = [
  qnn_target.Target(qnn_target.SocModel.SM8750),
  fallback_backend.FallbackTarget(),
]

compiled_models = aot_lib.aot_compile(
  str(model_path),
  target=target,
  keep_going=False,
)
```

**The SM8750 compile result should ideally be:**

```text
Subgraph 0 fully compiled: 71 / 71 ops offloaded to 1 partitions.
```

5. Export the compiled result as a Play AI Pack.

```python
ai_pack_export.export(
  compiled_models,
  str(AI_PACK_ROOT),
  AI_PACK_NAME,
  "mobilenet_v2_float",
)
```

The generated AI Pack layout is:

```text
ai_pack/mobilenet_v2_sm8750/src/main/assets/
  model#group_Qualcomm_SM8750/mobilenet_v2_float.tflite
  model#group_other/mobilenet_v2_float.tflite
```

The `model#group_other` fallback is required by `ai_pack_export.export(...)` for packaging completeness. The Android runtime still enforces NPU-only on physical devices.

6. Fetch Qualcomm QAIRT runtime libraries by running the script from the LiteRT NPU runtime package.

```sh
bash litert_npu_runtime_libraries/fetch_qualcomm_library.sh
```

This populates runtime modules with libraries such as:

```text
libLiteRtDispatch_Qualcomm.so
libQnnHtp.so
libQnnSystem.so
libQnnHtpV81Skel.so
libQnnHtpV81Stub.so
```

7. Include the SM8750 AI Pack and the matching Qualcomm runtime dynamic feature.

In `app/build.gradle.kts`:

```kotlin
if (enableNpu) {
  assetPacks.add(":ai_pack:mobilenet_v2_sm8750")
  dynamicFeatures.add(":litert_npu_runtime_libraries:qualcomm_runtime_v81")

  bundle {
    deviceTargetingConfig = file("device_targeting_configuration.xml")
    deviceGroup {
      enableSplit = true
      defaultGroup = "other"
    }
  }
}
```

`qualcomm_runtime_v81` is used because its manifest targets `Qualcomm_SM8750`. The other Qualcomm runtime modules target older SoCs such as SM8450, SM8550, SM8650, and SM8750. Including those in this SM8750-only sample make Bundletool reject the AAB because their device groups is not present in `device_targeting_configuration.xml`.

8. Enable Android Gradle Plugin device targeting support.

In `gradle.properties`:

```properties
android.experimental.enableDeviceTargetingConfigApi=true
```

This property was discovered from the local Android Gradle Plugin 8.13.1 classes after Gradle reported that device-group splits were not enabled.

9. Enforce NPU on physical devices.

```kotlin
if (!NpuCompatibilityChecker.Qualcomm.isDeviceSupported()) {
  error("Qualcomm NPU is required, but this device is not reported as supported.")
}

val env = Environment.create(BuiltinNpuAcceleratorProvider(context))
val modelProvider =
  AiPackModelProvider(context, AI_PACK_NAME, AI_PACK_MODEL_PATH) {
    setOf(Accelerator.NPU)
  }
val selectedModel = ModelSelector(modelProvider).selectModel(env)
val accelerators = selectedModel.getCompatibleAccelerators()
if (!accelerators.contains(Accelerator.NPU)) {
  error("AI Pack did not expose an NPU-compatible model for this device.")
}
```

10. Verify both build paths.

CPU/emulator build:

```sh
./gradlew testDebugUnitTest assembleDebug
```

NPU/AOT bundle:

```sh
./gradlew -PenableNpu=true bundleRelease
```
